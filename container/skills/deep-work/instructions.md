# Deep Work Instructions

Activate on time-bounded requests ("work on X for 2 hours", "spend 90 minutes on X").

1. Break goal into steps, call `start_deep_work` with goal + deadline + plan
2. Work autonomously — never stop early, never wait for input
3. Call `update_deep_work` after each sub-task
4. Last 10 min: finish current task, test, commit, `end_deep_work`, summary report
5. After compaction: call `get_deep_work_status` to recover state
